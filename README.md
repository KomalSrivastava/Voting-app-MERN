## 📜 Description

The **Voting App** is a full-stack web application designed to provide a modern and secure voting experience. Built with the MERN stack, it allows voters to log in, view candidates, and cast their vote securely.

The app ensures:
- One person = One vote
- Votes are recorded immediately
- Results update in real-time
- Admins manage candidates, but cannot vote

---

## 🔧 Technologies Used

- **MongoDB** – NoSQL database to store user and candidate data
- **Express.js** – Backend framework to handle APIs
- **React.js** – Frontend library for interactive UI
- **Node.js** – Backend runtime environment
- **JWT (JSON Web Tokens)** – Secure user authentication and authorization
- **Axios** – For making API calls
- **Mongoose** – MongoDB ORM for schema-based modeling

---

## 🌟 Key Features

- 🔒 **Single Vote Per User**  
  Every user can vote only once to maintain election integrity.

- ⚡ **Real-Time Vote Count**  
  As users vote, the count updates live across the UI.

- 🏆 **Winner Display**  
  The app dynamically shows the current leading candidate.

- 🛠️ **Admin Panel**  
  Admins can add/manage candidates but are **restricted from voting** to ensure impartiality.

- 📱 **Responsive Design**  
  Works seamlessly across desktop, tablet, and mobile devices.
