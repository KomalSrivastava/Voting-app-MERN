# 🗳️ Voting-app-MERN

Welcome to **Voting-app-MERN**, a secure and decentralized online voting platform powered by the **MERN stack** and **Web3** technologies. This project is my attempt to reimagine how elections can be conducted—transparent, tamper-proof, and accessible—from anywhere.

Whether you're a voter or an admin, the app ensures a seamless and trusted experience using **blockchain-backed smart contracts**.

---

## 🚀 Key Features

- ✅ **Decentralized Voting** — Every vote is recorded on the blockchain to prevent tampering.
- 👥 **User/Admin Dashboards** — Separate interfaces for voters and administrators.
- 📦 **Live Results** — View real-time vote counts directly from the Ethereum smart contract.
- 🧾 **Candidate Management** — Admins can add candidates before voting begins.
- 🔐 **Secure Login** — Simple and secure authentication for both roles.
- 🦊 **Web3 Integration** — Voters can cast their vote using MetaMask.
- 💡 **Solidity Smart Contracts** — Ensures each user votes only once.
